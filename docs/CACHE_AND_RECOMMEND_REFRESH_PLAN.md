# 缓存清理与推荐刷新实施计划

更新日期：2026-09-01

状态：用户已确认，可实施

## 1. 目标与边界

- 将自动播放音频、在线歌曲/歌单封面、推荐 JSON、搜索响应以及没有用户关系的纯浏览在线歌曲记录统一纳入“一键清空缓存”。
- 永久下载及下载清单、永久下载封面、本地歌曲及其封面、用户自选歌单封面、收藏、自建歌单、播放历史、播放次数、歌词、登录凭据和搜索历史必须保留。
- 刷新按钮放在侧边栏底部设置按钮右侧，不放在推荐页内容区；按钮始终可见。
- 点击刷新后重新绑定当前页面和全局控件状态，并强制刷新当前选中的网易云或 QQ 推荐。
- 不通过随机打乱伪造平台推荐变化；平台返回内容未变化时明确反馈。

## 2. 当前仓库事实

- `songs.cover_path` 和 `songs.cover_url` 只保存路径/URL 文本；实际图片位于 AppData 的 `covers/`。
- `LibraryService::clearCache()` 目前只清理自动播放音频及 `song_cache`，明确排除了封面。
- 搜索和推荐结果会通过 `upsertOnlineSong()` 长期写入 `songs`，纯浏览记录会逐步积累。
- 可见在线主页是 `RecommendPage` 的网易云/QQ 来源切换；`OnlinePage` 没有装入主窗口页面栈。
- 推荐页当前先加载旧缓存，失败后静默回退旧缓存；QQ 推荐歌单还错误使用用户云歌单，因此容易长期不变。

## 3. 一键清空缓存

### 3.1 清理内容

- 自动播放音频和 `song_cache`。
- 应用托管的在线歌曲封面与在线歌单封面。
- 网易云 `recommend.json`、QQ `recommend-qq.json`。
- `SearchCache` 下的搜索结果、联想和热搜响应；保留 QSettings 中的搜索历史。
- 满足以下全部条件的在线歌曲行：`source > 0`、不属于任何歌单、不在最近播放、不含播放统计、不含永久下载路径、不在当前播放队列、清理后不含自动缓存。

### 3.2 保护内容

- 永久下载文件、`.wycloudforge-downloads.json` 及其封面引用。
- `source == 0` 的本地歌曲和提取出的内嵌封面。
- `playlists.cover_path` 引用的用户歌单封面。
- 收藏、自建歌单、最近播放、播放次数、歌词、账号凭据和搜索历史。
- 任意不位于应用托管缓存目录的外部路径。

### 3.3 安全与反馈

- 只在事务中清理数据库引用和纯浏览歌曲行；删除失败的文件保留数据库引用并计入失败结果。
- 严格校验标准化绝对路径，禁止按任意 `cover_path` 删除外部文件。
- 清空 `CoverProvider` 内存缓存，并使用请求代次忽略清理前发出的迟到封面/推荐/搜索回调。
- 清理后执行 WAL checkpoint，不自动 `VACUUM`；SQLite 已释放页面可复用，实际大容量封面文件会立即释放磁盘空间。
- 设置页显示播放缓存、在线封面、推荐/搜索缓存、可删除浏览记录和总容量；完成后汇总删除数量、释放字节及失败项。

## 4. 侧边栏刷新按钮

- 放在 `SettingsFooter` 内、现有设置按钮右侧。
- 设置和刷新按钮均为 `28×28px`，间距 `12px`，左边距和底边距均为 `18px`。
- 用户提供的 `C:\Users\Fusssssion\Downloads\刷新.png` 作为资源；源图为 `200×200` 透明 PNG，运行时按 alpha 着色为 `#B8B8C4`。
- 图标视觉尺寸 `18×18px`；默认透明，悬停 `#1B1B24`，按下 `#24242E`，禁用 `#555563`。
- 不旋转、不增加任何动效；保留 tooltip、accessible name 和键盘焦点。

## 5. 刷新行为

1. 禁用按钮，阻止重复刷新。
2. 增加推荐和封面请求代次，使旧回调失效。
3. 重新读取曲库、歌单、收藏、下载和播放状态，刷新侧栏及当前页面。
4. 确保当前推荐来源服务可用；只刷新当前选中的网易云或 QQ，不同时唤醒两个来源。
5. 推荐歌曲与推荐歌单并行请求；成功部分立即替换，失败部分保留旧内容。
6. 更新来源独立缓存并记录 `version`、`updatedAtMs`、`playlistOffset`。
7. 请求结束后恢复按钮，并提示成功、内容未变化或失败原因。

## 6. 推荐内容规则

- 网易云推荐歌曲继续使用平台每日推荐；同一天可能不变。
- QQ 推荐歌曲优先账号每日推荐，旧接口失效时使用新歌推荐回退。
- QQ 推荐歌单改用 `topPlaylists()`，不再把用户云歌单当作推荐歌单。
- 每次手动刷新将当前来源歌单偏移增加 6；返回空列表时回到偏移 0。
- 手动刷新不先用旧缓存覆盖当前界面；网络失败时继续保留当前内容。
- 使用来源、请求代次和对象生命周期校验，防止切来源、退出登录或关闭窗口后串写。

- 覆盖 QQ 推荐歌单接口修正、来源隔离、并行请求、偏移轮换、内容未变化和失败保留旧内容。
