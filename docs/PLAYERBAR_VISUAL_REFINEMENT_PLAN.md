# 播放器与歌曲列表视觉细化计划

## 目标与边界

- 本轮只调整底部播放器、歌曲列表行末操作图标、搜索结果关键词高亮和对应资源。
- 保持播放、暂停、上一首、下一首、播放模式、歌词、播放队列、音量、收藏、下载、删除下载及来源切换的既有交互和信号契约。
- 不修改 `core/`、数据库、搜索排序、同曲合并、来源协议、登录或下载业务。
- 单个歌曲块继续适用于所有歌曲列表；本地、网易云和 QQ Logo 继续作为歌曲来源选择器。
- 按最新确认，删除在线/已缓存/已下载/本地的文字或图标标签，不引入“云”和“下载本地”状态图标。

## 1. 搜索关键词高亮

- 删除关键词匹配范围后的半透明红色矩形。
- 匹配文字继续使用主题红 `#EC4141`，其余文字颜色和省略规则不变。
- 不改变搜索算法、查询词规范化和搜索框文本选区样式。

## 2. 底部播放器

### 外观

- 固定高度由 `224px` 调整为 `204px`。
- 背景统一为页面底色 `#0E0E14`，不绘制独立灰底、渐变、模糊、阴影或分隔线。
- 删除 `PlayerBar::paintEvent()` 自绘背景，启用 `WA_StyledBackground`，由 `theme.qss` 统一绘制。
- 宽屏、中等和紧凑宽度的水平内边距分别为 `28px`、`20px`、`12px`；垂直内边距统一为 `12px`。

### 歌曲信息

- 左侧依次显示圆角封面、歌名和歌手；歌名在上，歌手在下。
- 宽屏封面 `128×128px`，中等宽度封面 `104×104px`，圆角 `12px`。
- 封面统一通过 `CoverProvider::coverFor(song, size, 12)` 生成，保留占位封面逻辑。
- 歌名和歌手均右侧省略；tooltip 保存完整文字。歌手对象名为 `playerArtist`，便于自动化测试和后续样式定位。
- 删除来源、缓存和下载状态标签。播放失败原因改放到播放器、标题和封面的 tooltip，并临时显示约 `3500ms` 的系统 tooltip。

### 横向布局

- `playerLeftBox` 不再按大比例拉伸，宽屏目标范围约 `270–360px`。
- `playerActionBox` 约 `72px`，收藏和下载按钮由纵向改为横向排列；按钮保持 `30×30px`，间距 `12px`。
- `playerCenterBox` 与 `playerRightBox` 按约 `45:55` 分配剩余空间。
- 右侧音量和工具控件左对齐，消除原布局左侧两段大面积空白，使主要控制区整体左移。
- `<780px` 时继续隐藏封面、歌词按钮、播放队列按钮和独立音量条；歌名、歌手、收藏、下载、进度、上一首、播放/暂停、下一首、模式和静音必须完整可用。

## 3. 播放器图标资源

使用以下用户资源，不修改源文件：

- `playbotton\列表循环.png` → `resources/icons/player-mode-loop.png`
- `playbotton\单曲循环.png` → `resources/icons/player-mode-single.png`
- `playbotton\随机播放.png` → `resources/icons/player-mode-shuffle.png`
- `Downloads\歌词.png` → `resources/icons/player-lyrics.png`
- `playbotton\播放列表.png` → `resources/icons/player-queue.png`

处理规则：

- 以源图 alpha 为遮罩，统一着色为 `#B8B8C4`，避免黑色源图在深色背景上不可见。
- 按有效 alpha 边界等比缩放并居中到约 `160×160px` 内容区；输出保持 `200×200px` 透明 PNG。
- 播放器绘制尺寸为 `20×20px`，点击区保持 `30×30px`。
- 播放模式索引保持 `0=列表循环`、`1=单曲循环`、`2=随机播放`。
- 上一首、播放/暂停、下一首和音量图标不改。
- 删除不再引用的 `icon-cloud.svg` 及其 QRC 项；不导入“云.png”和“下载本地.png”。

## 4. 歌曲行末图标

- 歌曲行高度保持 `112px`，收藏列保持 `64px`，下载列保持 `86px`。
- 收藏图标视觉边长由约 `18px` 增至 `24px`。
- 下载箭头整体按约 `1.3` 倍放大，线宽由 `1.7px` 调整到约 `2.2px`。
- 下载中圆环由 `16px` 增至 `21px`，删除垃圾桶由 `15px` 增至 `20px`。
- 所有状态严格以单元格 `rect.center()` 为视觉中心，去掉下载或删除悬停时的纵向偏移。
- 收藏和下载点击区域、悬停反馈与信号隔离不变；下载、完成和删除状态继续绑定真实 `DownloadService` 状态。

## 5. 自动化与目视验收

- 扩展 `tst_songlistview`，覆盖播放器 `204px` 高度、`#0E0E14` 背景、歌名/歌手、无状态标签、错误 tooltip、圆角封面、横向收藏/下载布局和五张新资源。
- 验证三种播放模式使用不同图标，关键词无红底但匹配文字仍为红色。
- 验证歌曲行收藏/下载视觉中心与单元格中心误差不超过 `1px`，点击收藏/下载/来源不会误触播放。
- 验证 `700px` 紧凑布局和 `150% DPI` 不裁切。
- 使用 `W:\build-ascii` 完整构建，运行 `tst_songlistview`、完整 Qt CTest 和 QQ Node 契约测试。
- 使用空音乐目录、独立数据库和独立设置目录生成 `1920×1080`、`1280×800`、`940×600`、搜索结果及 `125%/150% DPI` 截图，不读取真实曲库。
- 每个编译或测试失败均写入 `docs/HANDOFF.md`，记录命令、根因、环境归属和可行方案。
- 验证后提交并推送 `origin/main`，重新生成 `dist\NeteaseClone`，校验构建与发布 EXE 的 SHA-256 一致，并启动桌面快捷方式版本供预览。
